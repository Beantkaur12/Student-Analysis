🎓 Student Analysis Dashboard | Power BI
📊 Project Overview

The Student Analysis Dashboard is an interactive Power BI project designed to analyze student performance, attendance, age distribution, and academic trends across different courses, branches, and universities.

This dashboard transforms raw student data into meaningful visual insights, helping users understand academic performance and explore patterns in student attendance and marks.

🎯 Project Objectives
Analyze student marks across different courses.
Compare student attendance percentages across universities.
Understand age distribution across different branches.
Explore relationships between student attendance and academic performance.
Compare student performance across different hostels and day scholars.
Identify trends using interactive Power BI visualizations.
🛠️ Tools & Technologies Used
Power BI Desktop – Dashboard development and visualization.
Power Query – Data cleaning and transformation.
DAX – Data calculations and aggregations.
Data Visualization – Interactive charts, graphs, and KPI cards.
📈 Dashboard Features

The dashboard includes the following visualizations:

Course-wise Age and Marks Analysis – Compares the sum of student ages and marks across different courses.
University-wise Marks and Attendance Analysis – Displays marks and attendance trends across universities.
Hostel/Day Scholar Analysis – Analyzes attendance and age distribution by accommodation type, course, branch, and pass/fail status.
Attendance vs Age Analysis – Shows the relationship between attendance and age across different courses.
Branch-wise Age Distribution – Represents the distribution of student age across different branches using a doughnut chart.
Student Performance KPI Cards – Highlights marks for selected student categories.
📂 Dataset Columns

The dashboard uses a student dataset containing the following fields:

Column	Description
Age	Student age
Attendance(%)	Student attendance percentage
Branch	Academic branch
Course	Student course
Gender	Student gender
Grade	Student grade
Hostel/Day Scholar	Accommodation category
Marks(%)	Student marks percentage
Name	Student name
Pass/Fail	Examination result
University-ID	Unique university identifier
📊 Key Insights

The dashboard helps explore:

Differences in marks across various courses.
Attendance patterns across universities.
Age distribution among different academic branches.
Relationships between attendance and student demographics.
Differences in student performance based on accommodation categories.
Overall student academic performance.

Note: Actual findings should be interpreted based on the selected filters and underlying dataset.
